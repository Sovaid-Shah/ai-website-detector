Spot AI site-builder fingerprints on a live page

Detect is a free tool from AlgoVortex (algovortex.co), the same team behind the main site for product, SEO, and engineering work. We look for leftover hosts, badges, and CDNs from tools like Lovable, Bolt, Base44, Replit, Framer, and v0 preview.

Scan a URL Chrome extension Visit AlgoVortex

Straight talk: a public website almost never proves Cursor, Copilot, or ChatGPT wrote the code. Those tools leave normal React. If someone cleaned a Lovable export, we may show “not enough signal.” That is the honest answer.

Scan a website

Counts unique domains. Same site again is free. You always get the evidence list — we limit how many sites, not how clear the report is.

Scan a GitHub repo

Public repos work without a token. Private ones need GITHUB_TOKEN on the Worker. We check that GitHub returns the same owner/repo you typed before scoring Cursor / Codex / Copilot leftovers.

What we can catch

  • Default Lovable / Bolt / Base44 / Replit hosts and badges
  • Framer platform signals (platform, not “Framer AI”)
  • v0 preview hosts and tracking props
  • CDN and meta leftovers when nobody stripped them

What we cannot claim

  • Cursor vs VS Code vs Copilot vs ChatGPT as the author
  • Which navbar or page section was AI-written
  • Cleaned production exports with no builder leftovers
  • “100% AI-built” as a fact — only technical inference

Chrome extension

Same engine as this site, on the tab you already have open. Scan the tab, or paste a GitHub repo for Cursor / Codex leftovers. Store listing draft lives in the repo under apps/extension/STORE_LISTING.md.

Local load: build apps/extension, then Chrome → Extensions → Load unpacked → .output/chrome-mv3. Store zip: .output/ai-detectorextension-0.1.0-chrome.zip.
